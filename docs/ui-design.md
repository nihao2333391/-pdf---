# 五页界面设计规则与总览

## 当前优先规则：字体忠实度（用户手机反馈后修正）

用户明确喜欢 four-pages-detail-v1.png 的粗体与字号层次，并反馈前轮实际效果偏细。四页统一采用主标题 44rpx／700，栏目标签 32rpx／700，结果文档标题 36rpx／700；普通列表标题 34rpx／700、历史名称 36rpx／700，按钮以 32rpx／700 为主，双文件小按钮 28rpx／700。文件名及辅助说明保持常规字重，正文墨色 #172331。上述规则优先于下方历史稿的字号建议。

前轮 38rpx 主标题、28／29rpx 标签及 500／600 字重弱化了设计意图，本轮已调整。生成设计图缺少字体元数据，当前系统字体的实际字形随手机变化；模拟器观察到加粗增强，Android 仍待检查。证据截图 design/runtime/group-typography-v2.png、report-typography-v2.png。

最新实施：four-pages-detail-v1.png 已落实到四页源码。新增材料文件图标、紧凑排序行、两位序号、右侧历史时间、保存状态勾选图标，并调整字段、双文件操作和页码表尺寸。材料格式／大小说明继续显示，因此实际材料行较概念图略高；文件操作至少 44px 高。微信模拟器已显示列表和编辑空态，截图位于 design/runtime/；真实有材料状态、结果页和 Android 仍需验证。

最新四页细化稿：[报销列表、项目编辑、历史记录、生成结果](design/four-pages-detail-v1.png)。用户明确提出除首页外仍需完成 UI，本稿基于已确认 v3 生成，补齐材料排序／删除、两种保存、日期组织和输出文件动作。已目视检查；属于设计稿，供集中审阅，后续以真实运行画面对照完善。首页沿用已确认版本。

更新时间：2026-09-07。当前阶段：用户已确认五页总览 v3，五页原生源码已落实；电脑检查和原生模板编译通过，实际运行视觉及 Android 验收待完成。下方初稿过程作为历史依据。

当前实现：公共配色、按钮与线条位于 app.wxss，导航底色位于 app.json；五页布局和 sort-list 已同步。纸白 #FAF7F3、浅粉 #FBE2E3、浅灰褐 #E7DCD1、正文 #293C45、主按钮 #415A65。首页使用 assets/home-flow.png 柔和曲线背景、原生文字及 Tabler SVG 钱币／文档图标。其他页面保留原材料、草稿、错误、打开与分享的处理函数。

首页按内容宽高扣除底部安全区计算面积，两侧各留 6%，入口高度补偿横向留白。顶部为可用高度的 25%（最低 154px），新建最低 190px、历史最低 132px。375×667、390×700（安全区 34px）、412×780（安全区 24px）的源码计算达到 35%／20%；320×480 时历史为 24.2%，保留最小高度并允许滚动。实际微信尺寸及拇指触达待验证。

类型检查、19 项流程测试、6 份 WXML 与 7 份 WXSS 原生编译器检查通过。13 处图片引用有效，渐变资源已目视检查。开发工具当前为扫码登录页，实际五页运行截图待补；v3 继续作为设计对照图。完整状态见 ../design-qa.md。

## 1. 用户本轮提供的要求

- 全局色调主要参考所提供的配色照片，合理使用线条或图案分隔画面。
- 首页“新建报销”约占 35% 排版，钱的符号简图在中心。用户最新修正替代最初的至少 40%。
- 用户认可流动渐变方向，最新反馈是新建入口偏下，应放到拇指容易触达的位置。本轮压缩渐变区，将新建区域连同图标、文字整体上移，保留面积目标。
- 首页“历史记录”约占 20%，文档符号在中心。
- 首页上方采用流动感渐变色彩，移除原圆头短条装饰。用户最新修正替代最初的装饰方案。
- 主文案：“我便捷提交，你便捷查看”。“查看”对应报销内容简介 Word 文档的用途。
- 延续已确认的五页整体总览集中审阅：首页、报销列表、项目编辑、历史记录、结果。

参考图已保存为 [配色参考](design/palette-reference.jpg)。它只用于配色依据；图中文字属于参考材料内容。书名未提供。

新增 [流动构图参考](design/flow-reference.jpg)。新图用于参考柔和层叠构图；图中的天气内容与书页文字均为资料内容。全局仍沿用第一张配色图；新图的紫绿黄色未作为全局换色要求。

本轮采用的解释：面积分母为扣除微信导航栏后的首页可用内容面积；“流动感”为静态渐变的连续曲线与柔和层叠。本轮先制作静态设计稿，动态效果尚未确定。功能入口圆角沿用初稿，移除要求先按首页顶部装饰理解。

## 2. 全局规则表

| 对象 | 初稿规则 | 解决的问题 |
|---|---|---|
| 页面底色 | 纸白 #FAF7F3；浅粉 #F3E1E3 用于首页主入口和轻强调 | 保持柔和底色与主要操作层次 |
| 次要色 | 暖灰褐 #B5AAA0，用于历史入口及日期分隔带，可使用浅色版本 | 区别次要入口，保持同一配色体系 |
| 文字与按钮 | 深蓝灰 #415A65 用于主操作；墨色 #293C45 用于正文 | 让正文与动作在浅色面上清晰可读 |
| 点缀 | 珊瑚红 #DC655D，用于少量装饰和重点提示 | 控制视觉焦点；状态同时配文字，避免只靠颜色 |
| 配色依据 | 参考图中的浅粉、暖灰褐、深蓝灰、红四色关系 | 图片有拍摄光线影响；上述色值为屏幕设计建议，颜色审阅尚未通过 |
| 字号 | 手机逻辑尺寸正文 14—16px，主标题 26—30px，辅助文字优先 12—14px | 统一层次；最终以手机可读性检查为准 |
| 间距 | 页面左右约 24px，组内 8—12px，段间 20—24px | 保持内容对齐，减少零散分布 |
| 分隔 | 优先细线、日期浅色带及少量图案；普通列表用行分隔 | 清楚区分项目与材料，避免每行都套多层卡片 |
| 按钮 | 主操作深蓝灰填充；次要操作描边；文字用途明确，触控区域至少约 44px | 显示动作优先级，方便手机点击 |
| 图标 | 首页人民币符号简图与文档线图；其他页使用同一线条风格 | 让入口一眼可辨；最终图标资源在实现阶段选定 |
| 装饰 | 首页顶部改为浅粉、暖灰褐、淡蓝灰的柔和流动渐变；其余页当前布局沿用初稿 | 通过连续色彩层次丰富顶部，同时保持文字可读 |
| 空白状态 | 一句说明＋现有新增入口 | 告诉用户下一步；沿用空记录隐藏规则 |
| 处理中 | 按钮显示当前动作与进度，沿用已有重复操作保护 | 用户知道系统正在保存或生成 |
| 失败状态 | 清楚说明哪一项或材料失败，提供重试路径 | 保留草稿与上次输出，沿用既有业务规则 |

色值、字号和触控尺寸是后续实现建议。生成图不能替代颜色对比度测量、实际尺寸检查或手机排版验证。

## 3. 首页排版与文字

可用内容从上到下为：文案和流动渐变区 → 新建报销主区域 → 历史记录次区域。两入口上下布置，目标面积比例约为 35:20。

新建区域约占可用内容面积 35%，历史区域约 20%；最终以实际区域宽×高除以可用内容宽×高验收。不能仅按高度判断面积。实现时同时检查屏幕宽高、上下留白、微信导航和底部安全区域。

主文案按两行展示：

```text
我便捷提交，
你便捷查看
```

初稿辅助文案：“报销内容与凭证页码，一份 Word 说明清楚。”这是助手提出的补充文案，待集中审阅。

“新建报销”区域中央为人民币简图，下方放入口名称与“整理发票与附件”；“历史记录”区域中央为文档简图，下方放入口名称。整个区域作为入口。钱的图案仅表达报销主题，业务继续为材料整理。

### 拇指触达与位置修正

v3 缩短渐变区下方的装饰高度，新建入口整体上移。其图标与文字靠近内容区的中部，入口整块均可点击；历史入口在下方。页面位置需按实际可用高度排版，避免在不同手机上被固定顶部留白推低。

“拇指热区”在本任务中指用户自然单手握住手机时容易点中的区域。中心附近是本轮布局尝试，尚未通过手机验证。[单手拇指目标尺寸研究](https://www.microsoft.com/en-us/research/publication/target-size-study-for-one-handed-thumb-use-on-small-touchscreen-devices/)研究了位置与尺寸对点按的影响；本轮仅采用需结合点按验证的思路，不将旧设备实验转为当前手机的固定热区百分比。

真机验证：记录手机型号及常用握持方式；右手和左手分别自然握持，连续点击新建入口五次，记录是否调整握姿、过度弯曲拇指、伸手或误触历史。按实际感受微调入口位置。测试使用虚构记录，完全空白记录沿用已有清理规则。

## 5. 技术落实位置与验证计划

审阅后，公共色彩与文字样式落实到 miniprogram/app.wxss；微信导航栏配色落实到 app.json；首页结构与比例落实到 pages/home/index.wxml、index.wxss；其他四页与 sort-list 共用样式随整套设计调整。

页面继续调用现有仓库与服务。用户导入 → 本机保存原文件 → 生成快照 → PDF 与页码表 → Word → 结果保存的路径沿用原实现。本轮设计不改变生成规则。

实施验收：类型检查、相关模板编译、五页整体截图；Android 实测面积占比、文字对比、长文本、键盘、点击与拖拽，再执行 device-acceptance.md 的主流程。电脑测试、微信编译和手机结果分别记录。
