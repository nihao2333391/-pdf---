## 3. 接口与隐私用途核查表

| 当前调用 | 当前用途／数据路径 | 待确认事项 |
|---|---|---|
| wx.chooseMessageFile | 仅处理用户主动选中的聊天文件；复制至 USER_DATA_PATH/reimbursements/<id>/originals | 后台“选中的文件”相关声明与用途；同意和拒绝后的运行表现 |
| wx.chooseMedia | sourceType 为 album，mediaType 为 image；选图后本机保存 | “选中的照片或视频信息”候选声明应说明本程序只选图片；系统权限实际弹窗按设备核对 |
| wx.previewImage、wx.openDocument | 用户主动预览所选图片、PDF，打开生成的 PDF／DOCX | 当前平台是否要求附加声明以后台检测与官方当前文档确认；手机实际打开能力待测 |
| wx.shareFileMessage | 用户点击导出，通过微信选择目标后分享生成文件 | 声明应如实说明用户主动分享的路径；取消、失败和分享后打开分别验收 |
| 本机文件读写 | 保存描述、原材料、生成文件；历史记录留在本机 | 说明保存位置、保留条件、用户清理方式及旧文件积累；运营者联系信息由用户提供 |

建议用途文字草案：“用于导入您主动选择的报销发票、付款截图或行程单，在本机整理并生成凭证 PDF 和说明 Word。”此文字待结合后台实际字段核对后填写。本轮未写入后台。

源码缺少显式隐私授权处理是待验证点，尚不能据此判定必然失败。若平台默认授权流程可用，保留测试证据；若选择接口受阻，再根据原生小程序当前官方指南补适配。正式号后台声明与手机结果共同决定是否需要修改。

## 4. 账号后台集中取证清单

由用户参与一次核对以下信息，记录状态与日期即可。身份号码、AppSecret、验证码留在账号后台。

1. 账号主体类型、正式 AppID、管理员及开发者权限。
2. 当前可选类目、与本机文档整理相符的范围、需要的资质。
3. 认证是否必需，首次金额、有效期、续期金额与失败／退款规则。
4. 备案入口、提交资料、当前状态；通过后记录编号和展示位置。
5. 隐私指引声明、运营者联系方式；开发版／体验版／正式版各自生效情况。
6. 上传权限、实际代码包体积、体验成员设置、审核资料与版本状态。

后台缺少的信息继续标记待确认。确认费用或身份信息时再由用户作决定。
