## 下一次用户只需走一条完整流程

1. 用更新后的 Android 真机调试打开首页，新建报销。
2. 第一项填写描述，添加一份发票 PDF 和一张付款截图。
3. 点击“保存并添加下一项”，添加另一项描述及图片发票。
4. 返回列表，拖拽调整两项顺序，生成 PDF 和 Word。
5. 打开两份文件，核对页数、顺序、中文描述，并分别尝试导出到微信。
6. 返回首页进入历史记录，打开本次记录修改后再生成；完全关闭小程序后重开再检查一次。

以上合成一个验收回合。出现错误时记录具体操作、提示文字及对应材料格式。手机型号、微信版本、所用材料总大小随这一轮结果补记。
